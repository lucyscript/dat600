** c. Remove one edge to get a DAG
Removing \((F, B)\) breaks every directed cycle in Figure 1.

** d. General algorithm to transform a directed graph into a DAG
Run DFS and remove every back edge. In a directed graph, cycles appear exactly when DFS encounters a back edge, so removing all back edges leaves a DAG.
On Figure 1 plus \(I \rightarrow C\) and \(C \rightarrow A\), the removed back edges are \((C, A)\), \((F, B)\), \((I, C)\).
The resulting graph is a DAG: True.
Running time: \(O(V + E)\).

** d. Running time and improvement
Ford-Fulkerson runs in \(O(E \cdot |f^\ast|)\) for integral capacities, where \(|f^\ast|\) is the value of the maximum flow.
A standard improvement is Edmonds-Karp, which always picks the shortest augmenting path with BFS and runs in \(O(VE^2)\).
For larger networks, Dinic is usually faster in practice.
